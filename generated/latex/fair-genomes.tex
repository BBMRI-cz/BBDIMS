\textbf{Biobank Biosample and Data Integration Metadata Schema}
\newline

The Biobank Biosample and Data Integration Metadata Schema extends the MOLGENIS FAIR Genomes framework to standardise how biobank catalogues describe biological samples and their associated large-scale datasets. It links donor profiles, consent, and biospecimen records directly to multi-omics and imaging data using established ontologies. This structured approach facilitates seamless sample discovery, data harmonisation, and metadata exchange across biobank networks. Version 1.1-SNAPSHOT, 2026-10-15. This model consists of 19 modules that contain 307 metadata elements and 101705 lookups in total (excluding null flavors).
